# サインイン直後の着地（初期ワークスペース）

新しい利用者がサインインしたとき、どのページに着地し、最初のワークスペースが
どう作られるかを残す。

実装: `frontend/packages/frontend/core/src/desktop/pages/index/index.tsx`

---

## 流れ

```
サインイン → 着地ページ（/）
  ├ 自分のプライベートがある → 前回のワークスペース（無ければ自分のプライベート）の一覧（/all）へ
  └ 自分のプライベートが無い（新しい利用者・消した人）
       → createCloudWorkspace() を開始（非同期）
            1. プライベートを作る（kind: private）
            2. テンプレートのページ（「はじめに」など8件）を取り込む
       → 1 が終わると、ワークスペースの一覧の更新で、着地ページが再び動き、
         作られたワークスペースの一覧（/all）へ移動する
       → 2 が終わると、createCloudWorkspace() の完了処理が動く
```

### 見本のページは画面の言語で選ぶ（v0.3.0）

新しいワークスペースに取り込む見本は、作るときの画面の言語で日本語版と英語版を選ぶ。
日本語なら日本語版、それ以外は英語版（ガイドの入口 `userGuideUrl` と同じ判定）。

| | 日本語 | 英語 |
|---|---|---|
| 取り込む zip（`@ofuro/templates`） | `onboarding.zip` | `onboarding-en.zip` |
| 最初に開くページ | はじめに | Getting Started |
| フォルダの説明のページ | フォルダとタグの使い方 | How to Use Folders and Tags |
| 最初に作るフォルダ | はじめてのフォルダ | First Folder |
| Wiki のテンプレート（`createWikiTemplates`） | 日本語 | 英語 |

- 選ぶのは作るときだけ。あとで言語を変えても、取り込んだページは変わらない
- 題は zip の中の題と一致させる（最初に開くページとフォルダを、題で探すため）。単体テストで突き合わせる
- 英語版が無かったころ（v0.3.0-rc.1 まで）は、英語の画面でも日本語の見本が入っていた

「自分のプライベートがあるか」は `myPrivateWorkspaceId` で見る。共有に入っていても、プライベートが無ければ作る（#297）。
条件の経緯・失敗したときの扱い・1 人 1 つの守り方は [`workspace-model.md`](workspace-model.md) 12.3.1。

## ⚠️ 最初のフォルダと Wiki テンプレートが作られていなかった（2026-11-11）

### 事象

新しいワークスペースに、見本の 2 ページだけが入り、次の 2 つが作られていなかった。
エラーにはならず、コンソールに警告が出るだけだった。

- 「はじめてのフォルダ」（見本の「フォルダとタグの使い方」を入れる）
- Wiki のテンプレート 6 件（コンソールに `Failed to create wiki templates: Unreachable`）

段階 3（#151、2026-08）から。v0.3.0-rc.2 の作業中に、英語の見本を足したときに見つかった。

### 原因

作成の処理は、取り込んだ見本を**ページの一覧**から題で探し、テンプレートも一覧に載る前提で作る。
段階 3 から、一覧はサーバーの台帳から作る（`DocsStore.watchServerDocs`）。

- 作成の処理の中では、誰も一覧を購読していない。一覧は台帳を取りに行かず、空のまま
- 見本を探しても見つからない → フォルダを作らずに進む
- テンプレートを作ると、作った直後に一覧の記録を引く（`DocsService.createDoc`）。
  一覧が台帳を一度も受け取っていないので、作ったばかりのページも載らず `Unreachable` で止まる

### 対処

作成の処理の間、一覧を購読しておき、次を待ってからフォルダとテンプレートを作る。

1. 一覧の準備（`DocRecordList.isReady$`。台帳を受け取り、同期が済んだ）
2. 取り込んだ見本の 2 ページが一覧に載る（サーバーが写し取るまで少しかかる）

待つのは最長 60 秒。過ぎたら、それまでに見つかったものだけで進める（ワークスペースは作れている）。

### テスト

E2E: `e2e/integration.spec.ts` の #75 のテスト（日英の 2 つ）で、最初のフォルダと
テンプレートがあることも見る。修正前は、フォルダが無い所で落ちた。

## ⚠️ 着地の移動は1回だけ（#262、2026-10-12）

### 事象

新しい利用者がサインイン直後の数秒以内にページを開くと、一覧（`/all`）へ戻される。
もう一度開けば開ける。

### 原因

上の流れで、移動が**2回**起きていた。

```
6.4s  ワークスペースの一覧に現れる → 着地ページが /all へ移動（1回目）
      … 利用者がページを開く …
8.7s  テンプレートの取り込みが終わる → 完了処理が、もう一度 /all へ移動（2回目）← 戻される
```

着地ページは「移動済み」の印（`navigatedRef`）で2回目の移動を防いでいるが、
`createCloudWorkspace()` の完了処理はこの印を見ずに移動していた。

### 対処

完了処理でも「移動済み」の印を見て、すでに移動していれば何もしない。
まだ移動していなければ移動し、印を付ける。

テンプレートの取り込みが終わる前に一覧へ着地しても困らない。取り込んだページは
同期で一覧に順に現れる。

### テスト

E2E: `e2e/integration.spec.ts` の「サインイン直後に開いたページが、一覧へ戻されない（#262）」。
一覧に最初のページが出たらすぐ開き、8秒間、一覧へ戻されないことを見る。
修正前は4回中3回落ちた。
