# サインイン直後の着地（初期ワークスペース）

新しい利用者がサインインしたとき、どのページに着地し、最初のワークスペースが
どう作られるかを残す。

実装: `frontend/packages/frontend/core/src/desktop/pages/index/index.tsx`

---

## 流れ

```
サインイン → 着地ページ（/）
  ├ 自分のワークスペースがある → 前回のワークスペース（無ければ最初の1つ）の一覧（/all）へ
  └ 自分のワークスペースが無い（新しい利用者）
       → createCloudWorkspace() を開始（非同期）
            1. ワークスペースを作る
            2. テンプレートのページ（「はじめに」など8件）を取り込む
       → 1 が終わると、ワークスペースの一覧の更新で、着地ページが再び動き、
         作られたワークスペースの一覧（/all）へ移動する
       → 2 が終わると、createCloudWorkspace() の完了処理が動く
```

マニュアル専用のワークスペース（#72）は「自分のワークスペース」に数えない。

---

## ⚠️ 着地の移動は1回だけ（#262、2026-10-12）

### 事象

新しい利用者がサインイン直後の数秒以内にページを開くと、一覧（`/all`）へ戻される。
もう一度開けば開ける。

### 原因

上の流れで、移動が**2回**起きていた。

```
6.4s  ワークスペースの一覧に現れる → 着地ページが /all へ移動（1回目）
      … 利用者がページを開く …
8.7s  テンプレートの取り込みが終わる → 完了処理が、もう一度 /all へ移動（2回目）← 戻される
```

着地ページは「移動済み」の印（`navigatedRef`）で2回目の移動を防いでいるが、
`createCloudWorkspace()` の完了処理はこの印を見ずに移動していた。

### 対処

完了処理でも「移動済み」の印を見て、すでに移動していれば何もしない。
まだ移動していなければ移動し、印を付ける。

テンプレートの取り込みが終わる前に一覧へ着地しても困らない。取り込んだページは
同期で一覧に順に現れる。

### テスト

E2E: `e2e/integration.spec.ts` の「サインイン直後に開いたページが、一覧へ戻されない（#262）」。
一覧に最初のページが出たらすぐ開き、8秒間、一覧へ戻されないことを見る。
修正前は4回中3回落ちた。
