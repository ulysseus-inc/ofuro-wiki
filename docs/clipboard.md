# コピーと貼り付け（エディタ）

エディタ内のコピー・貼り付けは、ブラウザ標準ではなく **BlockSuite が自分で行う**。
ブロックの構造（見出し・リスト・書式）を保ったまま貼り付けるため。

この文書は、ofuro-wiki が上流から変えた振る舞いと、その理由を残す。

---

## 流れ

```
Ctrl+C
  → ブラウザ標準のコピーを止める（preventDefault）
  → エディタが把握している選択から、ブロックを切り出す（スライス）
  → クリップボードに書く
       text/plain … 文字列（他のアプリへ貼る用）
       text/html  … 表示用の HTML ＋ BlockSuite のスナップショット（埋め込み）

Ctrl+V
  → スナップショットがあれば、それを優先して取り込む
  → 無ければ text/html → text/plain の順に試す
```

| 場所 | 役割 |
|---|---|
| `blocksuite/affine/blocks/root/src/clipboard/readonly-clipboard.ts` | Ctrl+C の受け口（`onPageCopy`） |
| `blocksuite/affine/blocks/root/src/clipboard/page-clipboard.ts` | Ctrl+X・Ctrl+V の受け口 |
| `blocksuite/framework/std/src/clipboard/clipboard.ts` | 書き込み・読み出し。HTTP 環境の代替（メモリ上の控え）もここ |
| `blocksuite/affine/shared/src/adapters/middlewares/paste.ts` | 取り込むスライスを、貼り付け先に合わせて組み替える（`PasteTr`） |

HTTP 環境（非セキュアコンテキスト）での違いは [`deploy/README.md`](deploy/README.md) を参照。

## ⚠️ 選択が無いときのコピー（#253、2026-10-11）

### 事象

同じページ内でコピーして貼り付けると、**できるときとできないときがある**。
できないときは、貼り付けても何も起きない（画面にエラーは出ない）。
コンソールには次が出る。

```
TypeError: Cannot read properties of undefined (reading 'flavour')
    at new PasteTr (paste.ts)
```

### 原因

**エディタ側で何も選ばれていない状態で Ctrl+C を押すと、中身ゼロを書き込んでいた。**

```
Ctrl+C（エディタの選択は空）
  → ブラウザ標準のコピーを止める
  → 選択からブロックを切り出す … 0個
  → 「本文の入れ物（note）だけで、中身が空」のスライスを書き込む
     ・直前にコピーしていた内容は消える
     ・text/plain も入らない

Ctrl+V
  → スナップショットを見つけて取り込む
  → 入れ物を外すと中身は 0個
  → PasteTr が先頭のブロックを読みにいき、undefined で落ちる
```

画面では文字が選ばれて見えても、**エディタ側では選択が外れていることがある**
（例: 選んだあと Esc を押す。Esc は「文字の選択 → ブロックの選択 → 選択なし」と
段階的に外す）。コピーした瞬間の選択状態で結果が変わるため、
「できるときとできないとき」になる。

### 対処

1. **コピー: 切り出すブロックが無ければ、何もしない。** ブラウザ標準のコピーを止めず、
   クリップボードにも書かない。画面で文字が選ばれていればブラウザがそれをコピーし、
   何も選ばれていなければクリップボードは元のまま残る（OS の普通の振る舞いと同じ）。
   ⚠️ **切り取り（Ctrl+X）は何もしない。** ブラウザ標準にも任せない。
   標準の切り取りは画面の文字を直接消すため、エディタの中身（Yjs）を通らずに
   画面だけが変わる（PR #259 のレビュー指摘）。
   ⚠️ ブラウザ標準のコピーは文字列だけで、見出しや書式などのブロックの構造は持たない。
   エディタが選択を把握していないときに限った振る舞いで、閲覧専用のページでも同じ。
2. **貼り付け: スナップショットの中身が空なら、取り込まない。** 落ちずに、
   ほかの形式（text/html・text/plain）に回す。修正前のコピーで書き込まれた
   中身ゼロが、利用者のクリップボードに残っているため。

### テスト

E2E: `e2e/integration.spec.ts` の「コピー＆ペースト」

- 「エディタで何も選んでいないときのコピーで、クリップボードを壊さない」
- 「エディタで何も選んでいないときの切り取りで、何も変えない」
- 「中身ゼロのクリップボードを貼り付けても落ちない」
  （修正前のエディタが書き込んだ実物を採取して使う）
