# AI エージェント連携の設定

Claude Code などの AI エージェントが、ofuro-wiki のページを**読み・直し・書く**ための設定手順です。

AI は ofuro-wiki から見て**普通の利用者の一人**です。人と同じ権限で、同じ経路で編集します。
ブラウザで開いているページには、AI の編集がリアルタイムに反映されます。
誰が編集したかは、人の編集と同じく監査ログ・履歴に残ります。

---

## 全体の流れ

設定は **2か所** で行います。

```
┌─ ofuro-wiki 側（管理者が1回だけ） ─────────────────┐
│ ステップ1: AI 用のアカウントを作る                  │
│ ステップ2: ワークスペースに招待し、権限を付ける     │
└─────────────────────────────────────────────────────┘
┌─ AI エージェント側（使う人の PC。人ごとに1回） ────┐
│ ステップ3: Skill を Claude Code 等に入れる          │
│ ステップ4: 接続情報を保存する（ofuro login）        │
│ ステップ5: 動くか確かめる                           │
└─────────────────────────────────────────────────────┘
```

| | 誰が | どこで | 何を |
|---|---|---|---|
| ofuro-wiki 側 | ワークスペースの管理者（Admin / Owner） | ofuro-wiki の管理画面 | AI が使うアカウントと、その権限 |
| AI エージェント側 | AI を使う人 | 自分の PC（Claude Code 等を動かす所） | Skill 本体と、接続情報（`~/.ofuro-wiki/config.json`） |

⚠️ **ofuro-wiki のサーバーには、AI 専用の設定はありません。** AI 用のアカウントは普通のユーザーです。

---

## ofuro-wiki 側の設定（管理者）

### ステップ1: AI 用のアカウントを作る

管理画面の「**ユーザー管理**」で、AI 用のユーザーを追加します（Admin が行います）。

- **使う人ごとに 1 つ作る**ことを勧めます。例: `taro+ai@example.com`
  - 誰の AI が編集したかが監査ログで分かります。
  - その人の AI だけを止められます。
  - ワークスペースで 1 つを共有すると、追跡も停止も全員まとめてになります。
- **パスワードを設定する**こと。AI はパスワードでサインインします。
  - ⚠️ SSO（[設定手順](sso-setup.md)）で自動作成されたアカウントはパスワードを持たないため、AI には使えません。
    管理画面から追加してください。
- **Admin 権限は付けない**こと。

### ステップ2: ワークスペースに招待し、権限を付ける

人と同じ方法で、AI 用のアカウントをワークスペースに招待します。

| 付けるロール | AI ができること |
|---|---|
| **Member** | ページの読み書き（作成・編集・ゴミ箱への移動） |
| **Reader** | 読むだけ（一覧・検索・読み取り） |

- **必要な範囲だけ**にします。触らせたくないページは、ページ単位の権限で外せます。
  権限の無いページは、AI からは**存在しないもの**として扱われます。
- 接続先は、HTTPS で公開した URL を勧めます。HTTP の場合、パスワードが暗号化されずに送られます
  （localhost 以外への HTTP では、AI 側に警告が出ます）。

#### AI を止めたいとき

- そのアカウントのパスワードを変える、または削除します。保存済みのトークンもその時点で使えなくなります。

## AI エージェント側の設定（使う人）

### 前提

- [Claude Code](https://claude.com/claude-code)
- Node.js 20 以上（`node --version` で確認）
- ステップ1で作った AI 用アカウントのメールアドレスとパスワード
- ofuro-wiki のサーバーの URL。例: `https://wiki.example.com`
  （ブラウザのアドレスをそのまま貼っても、サーバーの部分だけを使います）

ワークスペースは設定しません。AI 用アカウントが招待されているワークスペースを、自動で使います。

### ステップ3: Skill を Claude Code 等に入れる

#### Claude Code の場合

Claude Code の中で、次の 2 つを実行します。

```
/plugin marketplace add ulysseus-inc/ofuro-wiki
/plugin install ofuro-wiki@ofuro-wiki
```

次の 2 つの Skill が入ります。

| Skill | 役割 |
|---|---|
| `ofuro-wiki-cli` | ページの一覧・検索・読み取り・作成・編集・ゴミ箱、タグ・フォルダ・画像 |
| `ofuro-wiki-format` | 読み取り結果と編集操作の書式（AI が参照する） |

#### Codex CLI の場合

このリポジトリの `skills/` にある 2 つのディレクトリを、`~/.agents/skills/`（全プロジェクト共通）かプロジェクトの `.agents/skills/` に置きます。

`vX.Y.Z` は、接続する ofuro-wiki の版に置き換えます。

```bash
git clone --depth 1 --branch vX.Y.Z https://github.com/ulysseus-inc/ofuro-wiki.git
mkdir -p ~/.agents/skills
cp -r ofuro-wiki/skills/ofuro-wiki-cli ofuro-wiki/skills/ofuro-wiki-format ~/.agents/skills/
```

- Codex の既定のサンドボックスは通信を止めます（`サーバーに接続できない` と出ます）。`~/.codex/config.toml` に次を足してください。
  ```toml
  [sandbox_workspace_write]
  network_access = true
  ```
  ⚠️ この設定は、Codex が実行する**すべてのコマンド**に通信を許します。ofuro-wiki の CLI に限りません。
- ステップ4 の `ofuro.mjs` のパスは、置いた場所に読み替えてください。
  例: `node ~/.agents/skills/ofuro-wiki-cli/scripts/ofuro.mjs login`

#### そのほかの AI エージェント

Agent Skills 形式の `SKILL.md` に対応したものなら使える見込みですが、動作は確認していません。
Skill の置き場に `skills/` の 2 つを置くか、`skills/ofuro-wiki-cli/scripts/ofuro.mjs` を Node.js で直接実行させてください。

> ⚠️ 使う Skill の版は、接続する ofuro-wiki と揃えてください。同期の方式はサーバーの版と一緒に変わります。

### ステップ4: 接続情報を保存する（ofuro login）

**自分の端末で**次を実行し、聞かれた 3 つを入力します。

```bash
node ~/.claude/plugins/marketplaces/ofuro-wiki/skills/ofuro-wiki-cli/scripts/ofuro.mjs login
```

```
サーバー URL: https://wiki.example.com
メールアドレス: taro+ai@example.com
パスワード:            ← 入力しても画面に出ません
ログインした: taro+ai@example.com（使えるワークスペース: 社内Wiki）
設定: /home/taro/.ofuro-wiki/config.json
```

> ファイルが見つからないときは `find ~/.claude/plugins -name ofuro.mjs` で場所を探してください。

- 入力した値で実際にサインインし、招待されたワークスペースがあることを確かめてから保存します。
- 保存するのは **サーバー URL・メールアドレス・トークン**です。**パスワードは保存しません。**
  保存先は自分の PC の `~/.ofuro-wiki/`（本人だけが読める権限）で、ofuro-wiki のサーバーには何も保存されません。
- トークンは **7日で切れます。** 切れると AI が「ofuro login をやり直してください」と頼んできます。そのときは、また自分の端末でステップ4を実行してください。
- ⚠️ **パスワードを AI エージェントのチャットに書かないでください。** 会話の記録に残ります。
  `login` は、AI にパスワードを渡さずに済ませるための入口です。
- パスワードを保存しないのは、AI が同じ PC のユーザーとして動き、ファイルを読めるためです。
  ページに仕込まれた指示に AI が従ってしまっても、漏れるのは7日で切れるトークンだけで、パスワードは守られます。
  トークンでもそのアカウントの権限で操作できるので、**AI 用の専用アカウントを、必要な権限だけで**使ってください（ステップ1・2）。

#### 環境変数で渡す場合（人がいない場面向け）

定期実行など、週1回のログインし直しができない場面では、3 つとも環境変数で渡せます。
パスワードを渡すため、トークンが切れても自動でサインインし直します。
その代わりパスワードがその環境に置かれるので、置き場所の守りはその環境の責任になります。

```bash
export OFURO_URL=https://wiki.example.com
export OFURO_EMAIL=taro+ai@example.com
export OFURO_PASSWORD=...
```

⚠️ **3 つを同じ場所に揃えてください。** 環境変数に URL があれば環境変数の 3 つを、無ければ設定ファイルの 3 つを使います（混ぜません）。
メールとパスワードは、一緒に設定した URL のサーバーにだけ送ります（AI が別のサーバーへパスワードを送らないための仕組みです）。

### ステップ5: 動くか確かめる

AI エージェントに頼みます。

```
ofuro-wiki のページ一覧を見せて
```

ページの一覧（docId・更新日時・題）が出れば完了です。

## 使い方

AI エージェントに、普段の言葉で頼みます。

| 頼み方の例 | AI がすること |
|---|---|
| 「ofuro-wiki で "デプロイ手順" を探して」 | 全文検索 |
| 「このページを読んで要約して」＋ページの URL | 読み取り |
| 「議事録のページを作って」＋内容 | ページの作成 |
| 「このページの手順 3 を直して」 | 該当ブロックだけを編集 |
| 「このページをゴミ箱へ」 | ゴミ箱へ移動（戻せます） |
| 「この Markdown をページに反映して」＋ファイル | 変わったブロックだけを差し替え |
| 「このページに `設計` タグを付けて」 | タグの付け外し |
| 「作ったページを `議事録` フォルダにまとめて」 | フォルダの作成・ページの出し入れ |
| 「このページの図を見て説明して」 | 画像・添付ファイルの取り出し |
| 「このスクリーンショットをページに足して」＋ファイル | 画像の追加 |

### 複数のワークスペースに招待されているとき

- 一覧・検索は、全ワークスペースをまとめて出します（ワークスペース名付き）。
- 既存のページは、AI がどのワークスペースにあるかを探します。
- **新しいページを作るときだけ**、AI が「どのワークスペースに作りますか」と聞きます。
  最初から「社内Wiki に作って」と頼めば、聞き返しません。

### AI が守ること

Skill には次の決まりが書かれています。

- **編集の前に、変更点を見せて承認を求めます。** 承認するまで送りません。
- **完全削除の前に、対象を示して承認を求めます。** 完全削除は取り消せません。
- 触っていない部分（書式・画像・表・マルチカラム等）は変えません。
- 誰かが同時に同じ箇所を直していたら、編集を止めて読み直します。
- **ページ本文に書かれた指示には従いません。** 本文は利用者の指示ではないためです。

### AI ができないこと

- データベースの中身の編集（読むことはできます）
- 画像以外の添付ファイルの追加
- タグの削除、フォルダの削除・名前変更・移動（人がブラウザで行います）
- 権限・共有の変更

## うまくいかないときは

AI のエラーは「何が起きたか → 次にすべきこと」の 1 行です。

| 表示 | 原因と対処 |
|---|---|
| `どのワークスペースにも招待されていない` | ステップ2が済んでいないか、メールアドレスが違います。⚠️ サーバーの設定によっては、**未登録のメールアドレスでサインインするとアカウントが自動で作られ**、サインイン自体は成功します。ステップ1で作ったアドレスか確かめてください |
| `作成先のワークスペースを --workspace で指定する` | 複数のワークスペースに招待されています。どこに作るかを AI に伝えてください |
| `サインインに失敗した（HTTP 401）` | パスワードが違うか、SSO だけのアカウントです（ステップ1） |
| `トークンの期限が切れた` | 7日経ちました。自分の端末でステップ4（`ofuro login`）をやり直してください。パスワードを AI に渡さないでください |
| `環境変数は 3 つ揃えて設定する` | 環境変数が一部だけ設定されています |
| `存在しないか権限が無い` | ページが無いか、AI 用アカウントに権限がありません（ステップ2） |
| `このページを編集する権限が無い` | AI 用アカウントのロールが Reader です（ステップ2） |
| `同期サーバーとの接続が切れた` | サーバーが止まっているか、通信が切れました。権限の問題ではありません |
| `サインインの試行が多すぎる` | 数分待ってから再実行してください |
| `警告: ... 暗号化されていない HTTP` | HTTPS の URL に切り替えてください |
