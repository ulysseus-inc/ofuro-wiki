# クイック検索（Ctrl+K）のコマンド

Ctrl+K（サイドバーの「クイック検索」）に出るコマンドの一覧と、動きの決まり（#321）。

## 1. 出すコマンド

| 分類 | コマンド | 動き | 条件 |
|---|---|---|---|
| ナビゲーション | すべてのドキュメントへ | 一覧へ移る | |
| | コレクションの一覧へ | コレクションの一覧へ移る | |
| | タグの一覧へ | タグの一覧へ移る | |
| | 設定に移動（Ctrl+,） | 設定の「見た目」を開く | |
| | アカウント設定に移動 | 設定の「アカウント」を開く | |
| | ゴミ箱に移動 | ゴミ箱へ移る | |
| 設定 | カラーモード・フォント・ページの幅・表示言語 | その場で切り替える | 今と違う値だけ出す |
| レイアウト | 左側のサイドバーを折りたたむ（Ctrl+/） | | |
| 作成 | 新しいページ・新しいエッジレス | 作って開く | |
| | 新規ワークスペース | 作成のダイアログを開く | システム管理者だけ（[`workspace-model.md`](workspace-model.md) 12.3） |

## 2. 出さないコマンド（2026-10-29 に消した）

AFFiNE の名残で、行き先が無い。

| コマンド | 消した理由 |
|---|---|
| ヘルプ › 新着情報 | 開く先（AFFiNE の更新履歴）が無い。押すとエラーになっていた |
| ヘルプ › お問い合わせ | 問い合わせ先が無い。「ofuro-wiki について」が開くだけだった |
| ナビゲーション › ワークスペースに移動 | 開く命令を受け取る画面が無く、何も起きなかった。切り替えはサイドバーで行う |
| 検索 › ローカル検索 | 「ローカル」が何を指すか伝わらない（ofuro-wiki にローカル保存は無い）。押す場面も無い（下の自動の切り替えがある） |

### ページの検索の行き先

ふだんはサーバーの全文検索で探す。0 件・エラーのときは、自動でブラウザの索引（同期済みのページから作る）で探し直す。
どちらで探しても、結果の見出しは「「○○」の検索」で同じにする（以前は後者に「(ローカル)」と付いていた）。

## 3. ダイアログを開くコマンドは、Ctrl+K が閉じきってから動かす

⚠️ Ctrl+K から設定を開き、閉じると、画面がクリックを受け付けなくなっていた（リロードで戻る）。

```
Ctrl+K の窓（@radix-ui/react-dialog: core の node_modules の写し）
  開く   → body の pointer-events を覚えて none にする（覚えた値 = ""）
設定の窓（@radix-ui/react-dialog: ルートの node_modules の写し）
  開く   → 覚えた値 = "none"（Ctrl+K がまだ閉じる途中のため）
Ctrl+K 閉じきる → "" に戻す
設定を閉じる    → "none" に戻す ← 固まる
```

同じ版の写しが 2 つあり、それぞれが別に覚えているのが原因。写しを 1 つにまとめる（依存の整理）は影響が広いため、
**コマンドは Ctrl+K の窓が閉じきってから動かす**ことで、覚える値が食い違わないようにする。

- コマンドは選んだ時点で積み、窓が閉じきったときに動かす。選ぶと必ず閉じ始めるので、積んだ分は必ず動く
- 閉じきる前（0.12 秒）に Ctrl+K を開き直したら、積んだ分は捨てる。残すと、あとで閉じたときに突然動く
