# ofuro-wiki E2E テスト

## 前提条件

以下のサービスが起動済みであること：

```bash
# 1. PostgreSQL
docker compose up -d

# 2. バックエンド (port 3010)
cd backend && npm run start:dev

# 3. フロントエンド (port 8080)
cd frontend && yarn dev
```

## セットアップ

```bash
cd e2e
npm install
npx playwright install chromium
```

## 実行

```bash
# ヘッドレス実行
npm test

# ブラウザ表示付き実行
npm run test:headed

# Playwright UI モード（デバッグに便利）
npm run test:ui
```

## 書き方の注意

### ⚠️ `isVisible({ timeout })` は待たない

Playwright の `isVisible()` は `timeout` を受け付けても**待たずに即答する**。
「出るまで待つ」つもりで書くと、画面が出る前に「見えない」と判定する。

```ts
// ✗ 待たない。出る前なら false が返る
if (await button.isVisible({ timeout: 60_000 })) { ... }

// ○ 本当に待つ
await button.waitFor({ state: 'visible', timeout: 60_000 });
```

`ensureSidebarOpen()` がこれで揺らいでいた（#258）。サインイン直後はサイドバーが
出る前に「見えない」と判定し、切り替えボタンを押して**開きかけのサイドバーを閉じていた**。
サイドバーの開閉は、外枠 `[data-testid="app-sidebar-wrapper"]` の `data-open` で読める。

### ⚠️ 新しい利用者のサインイン直後は、ページを開いても戻されることがある

新しい利用者でサインインした直後の数秒は、次の2つが起きている。

- アプリが初期設定の途中で、何度か一覧（`/all`）へ移動する。その前に開いたページは一覧へ戻される
- テンプレートのページが取り込まれて一覧が並び直される。押した瞬間に行が動くと、押しても開かない

ページを開くテストでは、**開いて中身が出るまで押し直す**（`expect(...).toPass()`）。
#75 のテストがこれで揺らいでいた（#258）。
