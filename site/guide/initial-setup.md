# 初期設定

導入が終わったら、社員に使ってもらう前に、root（最初の管理者）が次の 3 つを済ませます。

1. root としてサインインする
2. 新規登録を無効にする（必要に応じて）
3. 社内 Wiki 用の共有ワークスペースを作る

必要に応じて、4. のリンクプレビューも設定します。

## 1. root としてサインインする

`.env` の `ROOT_EMAIL` に書いたメールアドレスで、最初にサインインします。
パスワードを決めて「サインイン」を押すと「アカウントを作成」の画面が出るので、作ります。ここで決めたパスワードで、**root**（最初のシステム管理者）になります。

システム管理者になっているかは、左の「設定」を開いて確かめます。設定の左側に **「管理」** の欄（ユーザー管理・ワークスペース・サーバー設定・監査ログ・バックアップ・リストア）があれば、システム管理者です。

| 立場 | 誰 | できること |
|---|---|---|
| **root** | `.env` の `ROOT_EMAIL` の人（1 人） | システム管理者のすべて。誰にも消せず、管理者も外せない。すべての共有ワークスペースの持ち主 |
| **システム管理者** | root と、管理者にされた人 | ユーザーの管理・共有ワークスペースの作成と削除・サーバー設定・監査ログ・バックアップ |
| 一般ユーザー | それ以外 | 招待されたワークスペースを使う |

::: tip 管理用のアカウントと、普段のアカウントを分ける
root とシステム管理者は、すべての共有ワークスペースを開けます。普段の読み書きは、別に作った一般ユーザーのアカウントで行うことを勧めます。
2 人目からのシステム管理者は、設定 →「ユーザー管理」で追加します（[ユーザーとアクセス制限](./users-and-access#_7-システム管理者を増やす)）。
:::

## 2. 新規登録を無効にする

初期の設定では新規登録が有効になっており、Wiki の URL を開ける人なら誰でも、自分でアカウントを作れます（作る前に確認の画面が出ます）。
使える人をシステム管理者が決めたいときは、無効にしてください。

設定 →「**サーバー設定**」→「**新規登録を許可**」をオフにします。

![サーバー設定](/images/setup/server-settings.png)

無効にしたあとは、登録されていないアドレスでサインインすると「このパスワードは無効です」と出て、アカウントは作られません。
社員のアカウントは、システム管理者が作るか、ワークスペースへの招待のメール・リンクから本人が作ります（[ユーザーとアクセス制限](./users-and-access)）。

::: info 無効にしていても作れるアカウント
`ROOT_EMAIL` のアドレスと、招待のメール・リンクを受け取った人は、新規登録を無効にしていてもアカウントを作れます。
:::

## 3. 社内 Wiki 用の共有ワークスペースを作る

### ワークスペースの考え方

| 種類 | 誰が作るか | 誰が使うか | 使い方 |
|---|---|---|---|
| **共有** | システム管理者 | 招待された人 | **社内 Wiki**・部署ごとの Wiki。持ち主は root |
| **プライベート** | 自動（最初のサインインで 1 人に 1 つ） | 本人だけ | 下書き・個人のメモ。ほかの人を招待できず、システム管理者も開けない |

root が最初にサインインしたときに作られるのは、root の**プライベート**です。社内 Wiki には使わず、共有ワークスペースを作ります。

### 作る

1. 設定 →「管理」→「**ワークスペース**」→「**作成**」を押します。
2. 名前（例: `社内Wiki`）を入れて作ります。
3. 一覧の「**開く**」で、そのワークスペースに移ります。

部署ごとに分けたいときは、同じ手順で共有ワークスペースを増やします。招待されていない人には、ワークスペースごと見えません。

### 名前を変える

開いているワークスペースの名前は、設定 →「ワークスペース」→「**優先順位**」→「ワークスペース名」で変えます。
変更は、招待した全員に表示されます。

![ワークスペース名](/images/setup/workspace-name.png)

### 見本のページ

作ったワークスペースには、「はじめに」などの見本のページが入っています。読んでから消してかまいません。

## 4. リンクプレビューを使う（任意）

ページに URL を貼ったときの見え方を、よくする設定です。初期はオフです。

| | オフ（初期） | オン |
|---|---|---|
| URL を貼ったとき | リンクの文字のまま出る | ページの題・サムネイル付きのカードで出せる |
| サーバーから外部への接続 | **ない** | **ある**（貼られた URL のサイトへ） |

オンにすると、ofuro-wiki のサーバーが、貼られた URL のサイトへ接続して、題やサムネイルを取ってきます。
社内 Wiki の中身が送られるわけではありませんが、**どの URL を貼ったか**は相手のサイトに伝わります。
インターネットにつながないサーバーでは、オンにしても取得できません。

設定 →「**サーバー設定**」→「**リンクプレビュー・リッチ埋め込み**」をオンにします。

::: warning YouTube などの埋め込みは、この設定と関係なく使えます
「/」メニューの YouTube・Figma などで埋め込んだページは、オフのままでも動画などが表示されます。
このとき、**そのページを見た人のブラウザ**が、YouTube（広告の配信元を含む）などへ接続します。
社外に接続させたくない場合は、埋め込みを使わないよう、社内で決めておいてください。
:::
