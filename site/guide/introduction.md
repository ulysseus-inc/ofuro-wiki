# ofuro-wiki とは

ofuro-wiki は、自社のサーバーにデプロイ可能な社内 Wiki です。
Notion のようなブロックエディタで書き、社内の知識を共有できます。
全体が MIT ライセンスで、費用はかかりません。

## 特徴

| 機能 | 内容 |
|---|---|
| **書く** | `/` コマンド・ドラッグ&ドロップ・表・コードブロック・段組み。Markdown・HTML・Notion から取り込み、PDF・Markdown・HTML へ書き出し |
| **同時に編集** | 複数人が同じページを同時に編集でき、変更はすぐに相手の画面に出ます |
| **見つける** | 日本語に強い全文検索、バックリンク、`@` メンション、タグとフォルダ |
| **ワークスペース** | 自分だけの**プライベート**（下書き・メモ）と、招待した人で使う**共有**（社内 Wiki・部署ごとの Wiki）。共有はシステム管理者が作ります |
| **権限** | ワークスペースの役割（ワークスペース管理者・メンバー・閲覧者）と、ページごとの読み書きの権限 |
| **部外秘** | 見せる人を絞ったページは、ほかの人の一覧にも検索結果にも出ません。題も漏れません（ページに貼った画像・添付ファイルとコメントは絞れません） |
| **外部送信なし** | ofuro-wiki が自分から外部へデータを送ることは、一切ありません（テレメトリ・利用統計なし）。外部とつながるのは、利用者が YouTube などを埋め込んだときと、管理者がリンクプレビューをオンにしたときだけです |
| **監査ログ** | サインイン・ページの作成と変更・権限の変更・フォルダの操作などを記録します。ページを開いた記録も残せます（初めはオフ） |
| **運用** | 管理画面（ユーザー管理・ワークスペース・サーバー設定・バックアップと復元）、毎日の自動バックアップ |
| **シングルサインオン** | OIDC に対応。Google Workspace・Microsoft Entra ID・Keycloak などのアカウントでサインインできます。設定は管理画面だけで済みます |
| **使い方の説明** | この手順書と使い方は ofuro-wiki に入っていて、インターネットにつながなくても読めます |
| **スマホで使える** | スマホのブラウザで開くと、スマホ用の画面になります。アプリの導入は要りません |
| **AI エージェント** | Claude Code などから、ページを検索・閲覧・編集できます |

## 必要なもの

- **Docker** が動くサーバー 1 台
  - 社内で使うなら、Ubuntu Server（実機・仮想マシンのどちらでも）を勧めます（[社内サーバーへの導入](./install-server.md)）
  - Linux を用意できないときは、メモリ 8GB 以上の Windows 11 PC でも動きます（[付録](./install-windows.md)）
- 使う人の PC かスマホのブラウザ

外部のサービスには依存しません。
