# ユーザーとアクセス制限

誰が Wiki を使えて、どのページを見られるかを決めます。権限は 3 段階あります。

```
① サーバー         … サインインできるか（アカウントの有無）。システム管理者か（root を含む）
   └ ② ワークスペース … 招待されているか・役割（ワークスペース管理者・メンバー・閲覧者）
        └ ③ ページ      … ページごとに、見られる人・書ける人を絞る
```

::: info 権限の無いページは、存在ごと見えません
ofuro-wiki では、見る権限の無いページは、一覧にも検索結果にも出ません。題も分かりません。
:::

## 1. ユーザーを追加する

新規登録を無効にしたら（[初期設定](./initial-setup#_2-新規登録を無効にする)）、アカウントはシステム管理者が作ります。
招待のメール・リンクを受け取った人は、そこから自分でアカウントを作ることもできます（2.）。

### 1 人ずつ

設定 →「**ユーザー管理**」→「**ユーザーを追加**」で、メールアドレス・パスワード（8 文字以上）・名前を入れて「ユーザーを作成」を押します。

![ユーザー管理](/images/access/users.png)

作ったら、メールアドレスとパスワードを本人に伝えます。
受け取った人は、最初に 設定 → アカウント でパスワードを変えるよう案内してください。

### まとめて（CSV）

「**CSV で一括登録**」から、CSV ファイルで何人でもまとめて作れます（1 回 500 行まで）。

```csv
email,name,password
taro@example.com,山田 太郎,Temp-Pass-0001
hanako@example.com,鈴木 花子,Temp-Pass-0002
```

- 1 行目は見出し（`email,name,password`）。文字コードは UTF-8
- `email` と `password` は必ず書きます。`name` を空にすると、メールアドレスから作られます
- 「テンプレートをダウンロード」で、ひな形が手に入ります
- 読み込むと、まず 1 行ずつの OK・NG が出ます（**まだ登録されていません**）。確かめてから「○件を登録する」を押します

パスワードは自動では作られません。登録した後、本人にパスワードを変えてもらってください。

## 2. 共有ワークスペースに招待する

アカウントを作っただけでは、社内 Wiki のページは見えません。社内 Wiki の共有ワークスペースに招待します。
招待できるのは、システム管理者とワークスペース管理者です。プライベートには招待できません。

招待したいワークスペースを開き、設定 →「ワークスペース」→「**メンバー**」→「**メンバーを招待**」で、メールアドレスを入れて「招待を送る」を押します。カンマで区切れば、何人でもまとめて招待できます。

![メンバーを招待](/images/access/invite.png)

- **アカウントがある人は、その場でメンバーになります。** メールの設定が無くてもかまいません
- **アカウントの無い人**には招待のメールが届きます（メールの設定が要ります）。メールが無いときは、画面の右下に出る知らせの「URL をコピー」で招待の URL を写して、本人に渡します。受け取った人は、そこからアカウントを作り、「承認 & 参加」を押すと参加できます。新規登録を無効にしていても作れます
- 「招待リンク」の欄では、リンクを知っている人なら誰でも入れるリンクを作れます。社外に漏れると誰でも入れるので、使うときは期限を短くしてください

::: warning 招待の URL は本人にだけ
アカウントの無い人への招待の URL を持っていれば、誰でもそのメールアドレスでアカウントを作れます。本人以外に渡らない方法で送ってください。
:::

## 3. 役割を決める

共有ワークスペースの中での立場と、できることです。立場によって、決め方が違います。

| 立場 | 決め方 | 効く範囲 | できること |
|---|---|---|---|
| root（持ち主） | `.env` の `ROOT_EMAIL`（1 人） | **すべての**共有ワークスペース（招待は要りません） | すべて。共有ワークスペースの持ち主は、いつも root です（譲れません） |
| システム管理者 | 設定 →「ユーザー管理」でオンにする | **すべての**共有ワークスペース（招待は要りません） | root と同じ。ワークスペース管理者を選ぶ・外すのも、システム管理者だけです |
| ワークスペース管理者 | 招待した後、システム管理者が「︙」で選ぶ | そのワークスペースだけ | ワークスペースの設定・人の招待・メンバーと閲覧者の切り替え・書き出し |
| メンバー | 招待する（招待した直後はこの役割） | そのワークスペースだけ | ページの読み書き |
| 閲覧者 | 招待した後、「︙」で切り替える | そのワークスペースだけ | ページを読むだけ |

- ワークスペース管理者・メンバー・閲覧者は、ワークスペースごとに決めます。同じ人が、社内 Wiki ではメンバー、営業部の Wiki では閲覧者、ということができます
- root とシステム管理者は、どの共有ワークスペースも、設定 →「管理」→「ワークスペース」の「開く」から管理できます。ただし、ほかの人の**プライベートは開けません**

設定 →「ワークスペース」→「**メンバー**」で、その人の行の「︙」から変えます。

![役割の変更](/images/access/role-menu.png)

| メニュー | 中身 | 出る人 |
|---|---|---|
| 閲覧者（読み取りのみ）に変更 | 読むだけにする | システム管理者・ワークスペース管理者 |
| メンバー（編集可能）に変更 | 読み書きできるようにする | システム管理者・ワークスペース管理者 |
| ワークスペース管理者に変更 | ワークスペースの管理を任せる | システム管理者 |
| メンバーを削除 | ワークスペースから外す（アカウントは残る） | システム管理者・ワークスペース管理者 |

## 4. ページごとに見られる人を絞る

人事・経営のページなど、一部の人だけに見せたいページは、ページごとに絞ります。

1. ページを開き、右上の「**共有する**」を押します
2. 「一般アクセス」の「ワークスペースのメンバー」を「**アクセス不可**」にします
3. 「他のメンバーを招待」に名前を入れて、見せたい人を選びます
4. 右の権限を選んでから（下の表）、「**招待**」を押します

![一般アクセス](/images/access/general-access.png)

| 権限 | 読む | 書く・ゴミ箱へ移す | このページの共有の設定を変える |
|---|:-:|:-:|:-:|
| 管理可能 | ✅ | ✅ | ✅ |
| 編集可能 | ✅ | ✅ | ❌ |
| 読み取り専用 | ✅ | ❌ | ❌ |
| アクセス不可（一般アクセスだけで選べる） | ❌ | ❌ | ❌ |

- 「共有の設定を変える」は、ほかの人にこのページを見せる・外す、権限を変える、のこと。**管理可能の人は、さらに別の人へページを見せられます**
- アクセス不可の人には、ページは一覧にも検索結果にも出ません

![見せたい人を選ぶ](/images/access/share-invite.png)

人を選んだときの権限は、初めは「**編集可能**」です。読ませるだけなら「読み取り専用」に変えてから招待してください。
「管理可能」にすると、選んだ人がさらに別の人へページを見せられます。

::: warning 画像・添付ファイルとコメントは絞れません
ページに貼った画像・添付ファイルと、コメントは、ページの絞り込みが効きません。ワークスペースの人なら見られます。
見せる人がいつも同じ顔ぶれなら、その人たちだけの共有ワークスペースを作るほうが確実です。
:::

権限の無い人がページの URL を直接開くと、「アクセス権がない、または該当するコンテンツが見つかりませんでした」と出ます。ページがあるかどうかも分かりません。

::: info システム管理者とワークスペース管理者には見えます
共有ワークスペースでは、システム管理者・ワークスペース管理者は、ページの権限に関係なくページを開けます。管理する人が締め出されないようにするためです。
:::

## 5. パスワードを忘れた・端末をなくした

設定 →「ユーザー管理」で、その人の行の「︙」から行います。

| メニュー | 使う場面 |
|---|---|
| **パスワード変更URL発行** | 本人にパスワードを決め直してもらう。URL を本人に渡します（24 時間有効・1 回だけ使えます）。管理者はパスワードを知らずに済みます |
| **パスワードの再設定** | 管理者が新しいパスワードを決めて、本人に伝える |

**パスワードを変えると、その人のすべての端末でサインインが切れます。**
PC やスマホをなくしたときは、パスワードを変えれば、なくした端末からは使えなくなります。

::: warning 発行した URL はパスワードと同じ
URL だけでパスワードを変えられます。本人以外に渡らない方法で送ってください。閉じると、もう一度は表示されません。
:::

## 6. ユーザーを削除する

設定 →「ユーザー管理」で、その人の行の「︙」→「削除」を押します。取り消せません。

::: danger その人のプライベートは、一緒に消えます
削除すると、その人の**プライベート**も中のページごと消えます（確認の画面に、消えるワークスペースの名前が出ます）。
共有ワークスペースは消えません（持ち主は root のため）。残したいページは、削除の前に本人に共有ワークスペースへ移してもらってください。
:::

root は削除できません。

退職などで使えなくするだけなら、削除の代わりにパスワードを変える方法もあります（5.）。

## 7. システム管理者を増やす

設定 →「ユーザー管理」で、その人の行のスイッチをオンにすると、システム管理者になります。一覧には「システム管理者」の印が付きます（root には「root」）。

- root は、管理者を外せず、削除もできません。root を替えるときは、`.env` の `ROOT_EMAIL` を書き換えて起動し直します。共有ワークスペースの持ち主は、新しい root に移ります（前の root はシステム管理者のまま残ります）
- root のパスワードを変えられるのは、root 本人だけです

## 8. ログインの制限（設定は不要）

パスワードの総当たりを防ぐ仕組みが、初めから動いています。

| 制限 | 中身 |
|---|---|
| 失敗の回数 | 同じ接続元・同じアドレスで、5 分に 5 回まで |
| アカウントのロック | 続けて 10 回失敗すると、15 分ロック。15 分で自動で解除されます |

ロック中も、画面にはパスワードを間違えたときと同じ「このパスワードは無効です」が出ます（ロックされたことを攻撃者に教えないため）。

不審なサインインの試みが続くと、管理者全員にメールで知らせます。メールの設定（SMTP）が無いと届きません。

## 9. 誰が何をしたかを見る

設定 →「管理」→「**監査ログ**」で、サインイン・ユーザーの追加と削除・ページの作成と変更・権限の変更・フォルダの操作などの記録を見られます。
日時・利用者・操作で絞り込めます。見られるのはシステム管理者だけです。

### ページを開いた記録（任意）

設定 →「管理」→「サーバー設定」→「監査ログ」で、**誰がどのページを開いたか**も記録できます。初めはオフです。

- 記録するのは、共有ワークスペースのページだけです（プライベートは記録しません）
- 同じ人が同じページを 1 日に何度開いても、最初の 1 回だけを記録します
- 個人の行動の記録になります。オンにする前に、利用者に知らせてください。記録の量も増えます
