# Pages and blocks

## What is a block

A page body is a collection of "blocks". Each element — a paragraph, heading, bulleted list, image, table, or code — is a block.
You can rearrange blocks freely and build a page by combining them like parts.

## Creating a page

- Press **+** in the left sidebar, or **+** at the top right of **All docs**.
- Type the title at the top and press Enter to move to the body.

## Basic block operations

| Operation | How |
|---|---|
| Reorder | Drag the handle (⋮⋮) that appears to the left of a block |
| Change the type | Type `/` at the start of a line and pick a type ([Using the editor](./editor.md)) |
| Delete | Select the block and press Delete |

## Page hierarchy

- You can create child pages inside a page to build a hierarchy.
- The tree in the sidebar shows parent–child relationships.
- Use parent pages for broad topics and child pages for details.

## Organizing

| Method | When to use |
|---|---|
| Favorites | Pages you open often. Open them from near the top of the sidebar |
| Folders | Group pages into containers in the sidebar |
| Tags | Categories; a page can have several |
| Collections | Lists of pages gathered by a condition (such as a tag) |

In **All docs**, use the checkboxes to select several pages and act on them at once, or filter by tag or collection.
