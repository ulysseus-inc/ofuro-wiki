# Using the editor

## Page and edgeless

A page has two views. Switch between them with the button at the top.

| View | Good for |
|---|---|
| **Page** | Documents written top to bottom, such as meeting notes and procedures |
| **Edgeless** | A whiteboard-like canvas where you place things freely: diagrams, sticky notes, drawings, brainstorming |

## `/` commands

Type `/` at the start of a line to open a menu and insert a block.

| Group | Examples |
|---|---|
| Basic | Text, headings, bulleted list, numbered list, to-do, quote, code, divider |
| Media | Images, file attachments |
| Embeds | YouTube, GitHub, Figma, web bookmarks |
| Layout | Two columns, three columns |
| Database | Table, kanban |

Keep typing after `/` (for example `/heading`) to narrow the list.

## Formatting and pasting

- Select text to show the formatting menu (bold, italic, underline, strikethrough, inline code).
- Paste from other apps and the formatting is kept.

## Page width

Open **Info** under the page title and expand the hidden properties to find **Page width**. Choose standard or full width. Full width can be easier to read for pages with many tables or diagrams.

## Databases (table and kanban)

- Set a type for each column (text, number, select, multi-select, checkbox, date, member, and more).
- Switch between table and kanban to see the same data in different ways.
- Filter, sort, and group.

## Embeds

Paste a link to YouTube, GitHub, Figma, and so on, and it is shown as a card or an embed.

- Showing the title and image of a pasted URL (link preview) works only if your administrator has enabled it.
- For embeds such as YouTube, the viewer's browser connects to the outside site.

## Links to pages and mentions

Type `@` in the body to see candidate pages and members.

- **Pick a page** to insert a link to it. The linked page records it as a backlink ([Handy features](./features.md)).
- **Pick a member** to send them a notification.
- You can mention only people who are in the same workspace and can read the page.
