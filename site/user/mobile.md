# スマホで使う

スマホのブラウザで、PC と同じ URL を開くだけで使えます。アプリを入れる必要はありません。

## 開き方

- スマホのブラウザで、PC と同じ URL を開きます。スマホ用の画面が自動で出ます。
- ホーム画面に追加しておくと、アプリのように開けます。

## 画面の見方

画面の下の 4 つのアイコンで切り替えます。

| アイコン | 内容 |
|---|---|
| 家（ホーム） | 検索・最近開いたページ・お気に入り・フォルダ・コレクション・タグ |
| 書類 | すべてのドキュメント |
| カレンダー | 日記（日付ごとのページ） |
| えんぴつ | 新しいページを作る |

右上のベルで通知、歯車で設定を開きます。

## 書く

- 本文を押すと書けます。`/` のメニューも使えます。
- 文字を選ぶと、太字などの書式のメニューが出ます。

## PC との違い

- エッジレス（ホワイトボード）は、見ることはできますが、書くのには向きません。
- 細かい設定は PC の画面で行ってください。
- 書いた内容は PC と同じです。どちらで書いても、すぐに届きます。
