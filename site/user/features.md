# 便利な機能

## 検索

- 左のサイドバーの「クイック検索」（Ctrl+K）で、ページの題と本文を横断して探せます。
- 日本語の検索に対応しています。うろ覚えの言葉でも探せます。
- **読めないページは、検索の結果に出ません。** 題も出ないので、あることも分かりません。
- 同じ窓から、新しいページの作成や設定の切り替えもできます。

## リンク元

ほかのページから `@` でリンクすると、リンクされた側の下部の「Bi-Directional Links」（リンク元）に一覧されます。
「この手順書は、どの議事録から参照されているか」を後からたどれます。一覧は自動で更新されます。

## メンションと通知

- 本文やコメントで `@` からメンバーを選ぶと、その人に通知が届きます。
- 通知は、左のサイドバーの「通知」で見られます。

## テンプレート

- よく使う構成のページをテンプレートにしておくと、新しいページをその形から書き始められます。
- 議事録・日報・仕様書など、形をそろえたい文書に便利です。

## 保護モード（誤って書き換えない）

主に読むだけのページは、保護モードにしておくと、うっかり書き換えるのを防げます。

1. ページの題の下の「情報」を開き、一番上の「保護モード」に印を付けます。
2. 書ける人が開いても、読み取り専用で開きます。上部に帯が出ます。
3. 書くときは、同じところでオフにします。

保護モードは権限ではありません。書ける人なら誰でもオフにできます。読ませる人・書かせる人を絞るには [共有と権限](./sharing.md) を使います。

## 取り込みと書き出し

| 操作 | やり方 | 形式 |
|---|---|---|
| 取り込み | 左のサイドバーの「インポート」 | Markdown（画像などを含む zip も）・HTML・Notion の書き出し |
| 書き出し | ページの「…」→「エクスポート」 | PDF・Markdown・HTML など |
| 印刷 | 同じ「エクスポート」→「印刷」 | |

## 同時編集とオフライン

- 複数の人で同じページを同時に書けます。変更はすぐに全員に届きます。
- 通信が切れている間に書いたものも、つながったときに自動でまとめられます。

## ゴミ箱と復元

- ページを消すとゴミ箱に入り、そこから戻せます。
- ⚠️ **ゴミ箱で「完全に削除」すると、元に戻せません。**
- 前の内容に戻すこともできます（ページの「…」→「バージョン履歴を見る」）。
