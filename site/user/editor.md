# エディタの使い方

## ページとエッジレス

ページには 2 つの表示があり、上部のボタンで切り替えます。

| 表示 | 向いているもの |
|---|---|
| **ページ** | 上から下へ書く文書。議事録・手順書など |
| **エッジレス** | 広いキャンバスに自由に置く、ホワイトボードのような表示。図・付箋・手書き・アイデア出し |

## `/` コマンド

行の頭で半角の `/` を入力すると、メニューが開き、ブロックを入れられます。

| 分類 | 例 |
|---|---|
| 基本 | テキスト・見出し・箇条書き・番号付きリスト・ToDo・引用・コード・区切り線 |
| メディア | 画像・ファイルの添付 |
| 埋め込み | YouTube・GitHub・Figma・Web のブックマーク |
| レイアウト | 2 列・3 列 |
| データベース | 表・カンバン |

`/見出し` のように続けて入力すると、候補を絞り込めます。

## 文字の書式・貼り付け

- 文字を選ぶと書式のメニューが出ます（太字・斜体・下線・打ち消し線・インラインコード）。
- ほかのアプリから貼り付けると、書式を保ったまま入ります。

## ページの幅

ページの題の下の「情報」を開き、「他 6 件のプロパティ」を広げると「ページ幅」があります。標準と全幅を選べます。表や図が多いページは全幅が見やすいことがあります。

## データベース（表・カンバン）

- 列ごとに種類（テキスト・数値・選択・複数選択・チェックボックス・日付・メンバーなど）を決められます。
- 表とカンバンを切り替えて、同じデータを別の形で見られます。
- 絞り込み・並べ替え・グループ分けができます。

## 埋め込み

YouTube・GitHub・Figma などのリンクを貼ると、カードや埋め込みで表示されます。

- 貼った URL の題や画像を取り込んで表示する機能（リンクプレビュー）は、管理者が有効にしている場合だけ動きます。
- YouTube などの埋め込みは、見る人のブラウザが外部のサイトに接続します。

## ページへのリンクとメンション

本文で `@` を入力すると、ページとメンバーの候補が出ます。

- **ページを選ぶ**と、そのページへのリンクが入ります。リンクされた側には「リンク元」として記録されます（[便利な機能](./features)）。
- **メンバーを選ぶ**と、その人に通知が届きます。
- メンションできるのは、同じワークスペースにいて、そのページを読める人だけです。
