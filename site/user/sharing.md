# 共有と権限

誰がどのページを読めるか・書けるかの決まりです。

## 3 つの段

```
サーバー         … 管理者か、一般のユーザーか
 └ ワークスペース … どのワークスペースに、どの役割で入っているか
    └ ページ        … ページごとに、誰に読ませるか・書かせるか（絞らなければワークスペースの役割のまま）
```

## ワークスペースの役割（共有のワークスペース）

| 役割 | できること |
|---|---|
| ワークスペース管理者 | ページの読み書き・名前などの設定・人の招待・メンバーと閲覧者の切り替え |
| メンバー | ページを読む・書く・作る |
| 閲覧者 | ページを読むだけ |

- 招待された人は、はじめはメンバーです。役割はワークスペース管理者が変えます。
- ワークスペース管理者を選ぶのは、システム管理者です。
- システム管理者は、招待されていなくても、すべての共有のワークスペースを管理できます。
  ただし、ほかの人の**プライベートは開けません**。

## 人を招待する

ワークスペース管理者は、左のサイドバーの「メンバーを招待」から招待できます。

- アカウントがある人は、招待した時点でメンバーになります。
- アカウントの無い人には、招待のメールかリンクを送ります。受け取った人はそこからアカウントを作り、そのまま参加できます。

## ページごとに絞る

ページごとに、誰に読ませるか・書かせるかを決められます。

1. ページを開き、右上の「共有する」を押します。
2. 人を選び、権限を選びます（はじめは「編集可能」）。
3. ワークスペースの全員に対する既定（一般アクセス）も、同じ画面で変えられます。

| 権限 | 読む | 書く | このページの共有を変える |
|---|:-:|:-:|:-:|
| 管理可能 | ✅ | ✅ | ✅ |
| 編集可能 | ✅ | ✅ | ❌ |
| 読み取り専用 | ✅ | ❌ | ❌ |
| アクセス不可（一般アクセスだけで選べる） | ❌ | ❌ | ❌ |

- ⚠️ **読めないページは、一覧にも検索にも出ません。** 中身だけでなく、ページがあることも分かりません（題も見えません）。
- ワークスペース管理者は、ページで絞っても締め出されません。
- ⚠️ 閲覧者には、ページで「編集可能」を付けても書けません。書かせたい人は、ワークスペースでメンバーにしてください。
- ⚠️ ページに貼った画像・添付ファイルと、コメントは、ページの絞り込みが効きません。ワークスペースの人なら見られます。
  見せたくないものは、そのワークスペースに置かないでください。

## 部外秘のページを作る

人事・経営の資料など、ワークスペースの一部の人にだけ見せたいページは、次のように作ります。

1. ページを作り、**本文を書く前に**右上の「共有する」を押します。
2. 「ワークスペースのメンバー」を「**アクセス不可**」にします。
3. 「他のメンバーを招待」から、見せたい人を選び、権限を選びます（はじめは「編集可能」）。

選ばれていない人には、そのページが一覧にも検索結果にも出ず、題も見えません。URL を開いても「無い」と表示されます。

- ワークスペース管理者は、絞っても締め出されません（読めます）。
- 子ページ・フォルダには引き継がれません。**ページごとに**同じ設定をしてください。
- 見せた相手を「管理可能」にすると、その人がさらに別の人へ見せられます。広げたくなければ「編集可能」か「読み取り専用」にします。

::: warning 画像・添付ファイルとコメントは隠れません
ページに貼った画像・添付ファイルと、コメントは、ページの絞り込みが効きません。ワークスペースの人なら見られます。
部外秘の資料をファイルで置く場合や、見せる人がいつも同じ顔ぶれの場合は、**その人たちだけの共有のワークスペースを、管理者に作ってもらう**ほうが確実です。
:::

## 共有をやめる

「共有する」の画面で相手を外すと、その人の一覧からそのページが消えます。開いていた場合も、次に開いたときには見えません。
