features:
  - title: ブロックエディタ
    details: スラッシュコマンドやドラッグ&ドロップで、表や段組みを配置できます。<br>また、複数人で同時に編集できます。
  - title: 部外秘のページも書ける
    details: 見せる人を絞ったページは、ほかの人の一覧にも検索結果にも出ません。題も漏れません。
  - title: 外部送信なし
    details: テレメトリ・利用統計はありません。社内 LAN でもクラウドでも、ofuro-wiki から外部へデータを送りません。
  - title: Docker で動く
    details: Linux のサーバー 1 台と Docker で、社内 Wiki を立てられます。Windows PC でも動きます。
  - title: 日本語の全文検索
    details: 題だけでなく本文まで、日本語で探せます。<br>読めないページは結果に出ません。
  - title: プライベートと共有
    details: 下書きは自分だけのワークスペースに。社内 Wiki は管理者が用意した共有のワークスペースで。
  - title: 監査ログ
    details: 誰が・いつ・何をしたかを記録します。フォルダの操作や、ページを開いた記録も残せます。
  - title: AI エージェントとつながる
    details: Claude Code などの AI エージェントが、権限の範囲でページを探し・読み・書けます。
